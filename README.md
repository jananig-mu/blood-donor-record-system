# Blood Donor Record System (Streamlit + SQLite)

A student demonstration web application for donor record management.


## Features
- Dashboard and donor listing
- Search by name, city, or contact
- Filter by blood group
- Add, edit, and delete donor records
- SQLite database storage
- CSV export

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install requirements: `pip install -r requirements.txt`
4. Run: `streamlit run streamlit_app.py`


## Deployment
Deploy `streamlit_app.py` from this repository using Streamlit Community Cloud.\n
**Privacy:** This is a public demo. Use only fictional sample records; do not enter real donor names, phone numbers, or other personal data.
